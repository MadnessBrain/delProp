# Changelog

Все заметные изменения в расширении **delProp** будут документироваться в этом файле.

## [1.4.0] - 2026-07-22
### Добавлено
- **Таймер переработки до 19:00**: По окончании рабочего дня таймер переходит в режим отсчета переработки с надписью «Идет переработка» (до 19:00) как на главной странице, так и в электронном архиве.
- **Учет субботних переработок**: Все рабочие часы по субботам (до 19:00) теперь автоматически вносятся в копилку отгулов.
- **Цель по отгулам**: Во вкладке «Отгулы» добавлено поле для установки цели по часам отгулов с автоматическим расчетом оставшихся часов или уведомлением о достижении цели.

### Изменено
- **Рефакторинг вспомогательных функций времени**: Все функции форматирования и расчета рабочего времени (`calculateEndWorkTime`, `getOvertimeStatus`, `formatMinutes`, `parseTimeToMinutes`) централизованы в `utils/time.js` и повторно используются во всех модулях расширения.

## [1.3.2] - 2026-07-22
### Исправлено
- Автодополнение фильтра: исправлено отображение иероглифов в подсказке «Раскройте проект/группу для подсказок» — кириллические строки вынесены из `patch.js` в `filterAutocomplete.js`, чтобы не ломаться при обфускации.
- История фильтра: исправлено появление выпадающего списка автодополнения при навигации по истории стрелками ↑/↓ — теперь dropdown скрывается на время перехода между записями истории.

## [1.3.1] - 2026-07-13
### Исправлено
- Новости: исправлено отображение переносов строк в кастомных новостях. Символы `\n` в тексте новости теперь конвертируются в `<br>` при рендеринге.

## [1.3.0] - 2026-07-10
### Добавлено
- **Автодополнение фильтра**: при вводе текста в фильтр проектов электронного архива появляется выпадающий список подсказок из реальных данных дерева. Подсказки контекстные: на уровне проекта — проекты, после точки/запятой — группы, после двух разделителей — чертежи. Навигация стрелками ↑/↓ и выбор Enter/кликом. Если проект/группа ещё не раскрыты — показывается подсказка «Раскройте проект для подсказок».
- **История поиска**: навигация по предыдущим запросам стрелками ↑/↓ (как в терминале). Enter сохраняет запрос в историю. При достижении конца истории — восстанавливается текущий ввод. История сохраняется между сессиями (до 50 записей). Дубликаты автоматически перемещаются в конец.
- Новые модули: `archive/filterHistory.js`, `archive/filterAutocomplete.js`.

## [1.2.9] - 2026-07-10
### Изменено
- Правила проекта: обновлен регламент написания новостей (`AGENTS.md`). Новости должны содержать исключительно новые возможности, улучшения работы и подробные инструкции для пользователя, без технических деталей об изменениях структуры кода и архитектуры.

## [1.2.8] - 2026-07-10
### Изменено
- Рефакторинг таймера: вся логика таймера рабочего времени в электронном архиве вынесена из `saveAddres.js` в новый файл `archive/archiveTimer.js` в соответствии с архитектурным правилом «новые фишки -> новый файл».
- Общие хелперы времени: функции `parseTimeToMinutes`, `timeNorm` и `getPerDay` объединены в единый хелпер `utils/time.js` и используются совместно как в `home` (главная страница через `core.js`), так и в `archive` (через `archiveTimer.js`), полностью устранив дублирование кода времени.

## [1.2.7] - 2026-07-10
### Добавлено
- Настройка в попапе: добавлена опция «Кэшировать дерево проектов» (по умолчанию включена), позволяющая полностью отключить кэширование структуры дерева в локальное хранилище.

### Исправлено
- Фильтр проектов: исправлена отмена фильтрации групп при раскрытии проектов, когда применен умный иерархический поиск (с точкой/запятой). DOM-фильтр теперь игнорирует обновление структуры, если активен умный поиск.

## [1.2.6] - 2026-07-10
### Исправлено
- Фильтр проектов: исправлено пропадание проекта при вводе точки после номера (например, `23680.`). Причина — `MutationObserver` вызывал DOM-фильтр, который сравнивал полный запрос с точкой и не находил совпадения.
- Фильтр проектов: исправлено невосстановление видимости проектов при очистке строки поиска. Теперь при очистке сначала сбрасывается состояние DHTMLX-дерева, а затем применяется фильтр по пинам.
- Фильтр проектов: исправлено пропадание закрепленных проектов после фильтрации и очистки поля (например, `MPSV06M` пропадал после фильтра `23680` и удаления текста).
- Кэш дерева архива: исправлена кодировка кириллических названий групп (например, «Письма», «Извещения»). Сервер отдаёт XML в windows-1251, но фоновая перевалидация использовала `fetch().text()` с UTF-8. Заменено на `arrayBuffer()` + `TextDecoder('windows-1251')`.

## [1.2.5] - 2026-07-09
### Исправлено
- Фильтр проектов в электронном архиве: восстановлен поиск проектов по части номера (например, ввод «236» отображает проекты «23630» и «23680») без автоматического раскрытия структуры.
- Устранена ошибка исчезновения групп при поиске по группе/проекту за счет перехода на подстрочный поиск (`includes`) вместо строгого префикса.
- Добавлена поддержка запятой `,` в качестве разделителя иерархических уровней наравне с точкой `.` (например, `23680,362125` работает аналогично `23680.362125`).

## [1.2.4] - 2026-07-08
### Добавлено
- Кастомизация таймера (стакана) рабочего дня: добавлено 11 новых красочных интерактивных тем с анимацией (Пиво, Mountain Dew, Кола, Бутылка, Секундомер, Солнце, Ракета, Растение, Батарея, Чайник, Пицца, Попкорн, Вино, Машина, Звезды).

- Группировка списка тем таймера: все темы в выпадающем списке настроек сгруппированы по категориям («Напитки и еда», «Природа и космос», «Техника и транспорт»).
- Форматированный экспорт отгулов в Excel: таблицы генерируются со стилями по шаблону (шрифты Arial, тонкие рамки, серая заливка шапки, формулы суммирования, объединенные ячейки ФИО и подписей).
- Дублирование таймера на странице архива: отображение прогресса дня и расчетного времени выхода в правом верхнем углу панели электронного архива.
- Переработан интерфейс попапа настроек: шапка и вкладки зафиксированы на месте (position: sticky), настройки пользователя перенесены на отдельный экран по клику на шестеренку, визуально разделены настройки и портал.
- Убрана квадратная серая рамка при наведении на кнопку шестеренки.

## [1.2.3] - 2026-07-08
### Исправлено
- Сбой загрузки и работы скрипта архива: устранена критическая ошибка `TypeError` в строгом режиме, возникавшая из-за использования `arguments.callee` в коде валидации целостности архива.
- Запрет инлайнового выполнения скриптов (CSP): механизм взаимодействия с функциями страницы электронного архива переписан с использованием инжектируемого скрипта-моста `archive/patch.js`, загружаемого через `chrome.runtime.getURL`.
- Раздельные файлы архива в полной сборке: отключено принудительное объединение (bundling) файлов архива в Full-версии; файлы `tabSync.js`, `projectFilter.js`, `saveAddres.js` теперь сохраняются раздельными и подключаются поочередно через `manifest.json`.
- Передача и запоминание адресов/ID документов: исправлена логика определения активного документа — теперь данные запрашиваются асинхронно из контекста страницы через API `GetCurrentDocID`/`GetCurrentDocName`, гарантируя точную передачу ID документа в хэш URL.

## [1.2.0] - 2026-07-07
### Добавлено
- Экспорт отгулов в Excel: в попапе настроек в блоке «Отгулы» добавлена кнопка «Экспорт в Excel». - Исправлен баг удаления новостей: список новостей в хранилище (`newsId`) теперь накапливается, а не перезаписывается, предотвращая повторное появление обычных новостей при блокировке всех новостей (обычных + кастомных).
- Исправлено состояние гонки в очистке новостей: добавлена повторная проверка в течение 250 мс, если класс элемента или атрибут ID ещё не инициализированы.
- Полностью удалены конфигурации футбольных кнопок / Sport-Express из настроек по умолчанию в `background.js`.

## [1.0.1] - 2026-06-26
### Добавлено
- Создана настройка `headerEnabled` в попапе, позволяющая включать/выключать верхнюю шапку отдельно от таймера.

### Изменено
- Откачен фильтр дерева архива к простому поиску проектов и закреплению (убран выпадающий список выбора групп) и реализовано сохранение состояния кнопки закрепа (`archiveShowPinnedOnly`).
- Реструктуризированы скрипты в папке `home/`: разделены файлы `features.js` и `pivo.js` на модули (`core.js`, `news.js`, `sidebar.js`, `misc.js`, `header.js`, `header.css` и `pivo.js`).
