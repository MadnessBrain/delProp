# delProp — Улучшайзер для КБ Вымпел

[![Version](https://img.shields.io/badge/version-1.5.2-blue.svg)](manifest.json)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-orange.svg)](manifest.json)

Браузерное расширение для Chrome (Manifest V3), улучшающее работу с внутренними веб-ресурсами КБ Вымпел: корпоративный портал и электронный архив документов.

---

## ✨ Возможности

### Главный портал (`pcserv.vympel`)
*   **Таймер рабочего дня** — визуальный виджет внизу экрана с анимированными темами (Пиво, Ракета, Чайник, Пицца и т.д.). Показывает прогресс рабочего дня, учёт перекуров и обеда, предупреждает о времени выхода. После 19:00 автоматически переходит в режим учёта переработок.
*   **Шапка с прогрессом** — сворачиваемая плавающая панель вверху: имя пользователя, время входа/выхода, предсказание выхода с учётом опозданий.
*   **Учёт переработок (Отгулы)** — автоматический парсинг логов активности. Считает опоздания (до 30 мин сдвигают выход), поддерживает ручной ввод для дней без пропуска. Раздельный учёт: «Отгулы» и «💰 За деньги».
*   **Очистка новостей** — скрытие стандартных новостей портала, добавление кастомных новостей расширения.
*   **Цветовые темы** — кастомизация интерфейса портала (основной цвет, фильтры, снег и другие визуальные эффекты).

### Электронный архив (`archive.vympel`)
*   **Умный фильтр проектов** — поиск по дереву документации с автодополнением, историей запросов (стрелки ↑/↓ как в терминале) и запоминанием активной вкладки.
*   **Закреплённые проекты** — возможность «запинить» часто используемые проекты с кнопкой быстрого фильтра.
*   **Синхронизация вкладок** — автоматическое сохранение и восстановление последнего открытого документа.
*   **Кэширование дерева** — локальное кэширование структуры проектов для мгновенной загрузки.

## 🚀 Установка

### Для пользователя (установка собранной версии)
1.  Скачайте или склонируйте этот репозиторий.
2.  Откройте Chrome и перейдите на `chrome://extensions/`.
3.  Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4.  Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5.  Выберите папку `dist/full/` из проекта.

### Для разработчика (сборка из исходников)
1.  Убедитесь, что установлен [Node.js](https://nodejs.org/).
2.  Установите зависимости: `npm install`
3.  Соберите проект: `node build.js`
4.  Загрузите `dist/full/` в Chrome как распакованное расширение.

## 🏗️ Структура проекта

```text
delProp/
├── manifest.json          # Конфигурация расширения (MV3)
├── background.js          # Фоновый сервис-воркер
├── build.js               # Скрипт сборки (esbuild minification)
├── popup.*                # Интерфейс настроек и учёта отгулов
├── db/
│   └── db.json            # База новостей и данных расширения
├── home/                  # Модули для главного портала
│   ├── core.js            # Ядро: инициализация, хелперы, Mutation Observer
│   ├── header.js          # Плавающая шапка с прогрессом
│   ├── news.js            # Управление новостями
│   ├── misc.js            # Парсинг активности, переработки, модальные окна
│   ├── pivo.js            # Entry-point таймера
│   └── pivo/              # Подмодули таймера (разделены по ответственности)
│       ├── messages.js    # Тексты уведомлений для всех тем
│       ├── themes.js      # HTML-шаблоны 14 визуальных тем
│       ├── render.js      # Рендеринг прогресса по темам
│       └── core.js        # Логика таймера, перекуры, расчёт времени
├── archive/               # Модули для электронного архива
│   ├── filterHistory.js   # История поиска с привязкой к вкладкам
│   ├── filterAutocomplete.js # Автодополнение из дерева документов
│   ├── projectFilter.js   # Основной фильтр и «закрепы»
│   └── saveAddres.js      # Сохранение вкладок и синхронизация
├── patch/                 # Скрипты для инъекции в контекст страницы
└── utils/                 # Общие утилиты
    ├── time.js            # Расчёт рабочего времени, опозданий, форматирование
    └── settings.js        # Дефолтные настройки (single source of truth)
```
