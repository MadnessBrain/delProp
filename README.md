# delProp — Улучшайзер внутреннего портала

[![Version](https://img.shields.io/badge/version-1.5.2-blue.svg)](manifest.template.json)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-orange.svg)](manifest.template.json)

Браузерное расширение для Chrome (Manifest V3), улучшающее работу с внутренними веб-ресурсами: корпоративный портал и электронный архив документов.

> **Важно:** реальные адреса сайтов, на которых работает расширение, **не хранятся в репозитории**. Они задаются локально в `hosts.json` (см. раздел [Конфигурация хостов](#-конфигурация-хостов)). В git попадает только `hosts.example.json` с заглушками.

## ✨ Возможности

### Главный портал
*   **Таймер рабочего дня** — визуальный виджет внизу экрана с анимированными темами (Пиво, Ракета, Чайник, Пицца и т.д.). Показывает прогресс рабочего дня, учёт перекуров и обеда, предупреждает о времени выхода. После 19:00 автоматически переходит в режим учёта переработок.
*   **Шапка с прогрессом** — сворачиваемая плавающая панель вверху: имя пользователя, время входа/выхода, предсказание выхода с учётом опозданий.
*   **Учёт переработок (Отгулы)** — автоматический парсинг логов активности. Считает опоздания (до 30 мин сдвигают выход), поддерживает ручной ввод для дней без пропуска. Раздельный учёт: «Отгулы» и «💰 За деньги».
*   **Очистка новостей** — скрытие стандартных новостей портала, добавление кастомных новостей расширения.
*   **Цветовые темы** — кастомизация интерфейса портала (основной цвет, фильтры, снег и другие визуальные эффекты).

### Электронный архив
*   **Умный фильтр проектов** — поиск по дереву документации с автодополнением, историей запросов (стрелки ↑/↓ как в терминале) и запоминанием активной вкладки.
*   **Закреплённые проекты** — возможность «запинить» часто используемые проекты с кнопкой быстрого фильтра.
*   **Синхронизация вкладок** — автоматическое сохранение и восстановление последнего открытого документа.
*   **Кэширование дерева** — локальное кэширование структуры проектов для мгновенной загрузки.

## 🔧 Конфигурация хостов

Адреса сайтов вынесены из исходников в отдельный конфиг, чтобы не попадать в публичный репозиторий.

| Файл | Назначение | В git |
|------|------------|:-----:|
| `hosts.example.json` | Шаблон с заглушками (`*.example.internal`) | ✅ |
| `hosts.json` | Реальные адреса портала и архива | ❌ (`.gitignore`) |
| `manifest.template.json` | Шаблон манифеста с плейсхолдерами матчей | ✅ |
| `manifest.json` | Готовый манифест (генерируется) | ❌ (`.gitignore`) |
| `hosts.generated.js` | Runtime-конфиг для popup и content-скриптов (генерируется) | ❌ (`.gitignore`) |

**Первый запуск:**
1.  Скопируйте пример в рабочий конфиг: `cp hosts.example.json hosts.json`
2.  Впишите в `hosts.json` реальные адреса портала и архива.
3.  Сгенерируйте манифест и runtime-конфиг: `node gen-manifest.js`

Структура `hosts.json`:
```jsonc
{
  "manifest": {
    "mainMatches":     ["https://<портал>/*"],          // content_scripts главного портала
    "archiveMatches":  ["http://<архив>/*"],             // content_scripts архива
    "resourceMatches": ["https://<портал>/*", "..."]     // web_accessible_resources
  },
  "runtime": {
    "activityEndpoint":     "https://<портал>/<скрипт>.php", // patch.js: полный адрес запроса активности к БД
    "popupActiveTabUrl":    "http://<портал>/*",          // popup.js: запрос активной вкладки
    "authorUrl":            "https://<сайт-автора>",       // popup.js: ссылка в копирайте
    "allowedHostFragments": ["<портал>", "<архив>"]       // popup.js: домены для перезагрузки
  }
}
```

`gen-manifest.js` подставляет `manifest.*` в `manifest.template.json` → `manifest.json`, а `runtime.*` — в `hosts.generated.js` (глобал `DELPROP_HOSTS`, который читают `popup.js`, `home/misc.js` и `patch/patch.js`). Если `hosts.json` отсутствует, генератор использует заглушки из `hosts.example.json`.

## 🚀 Установка

### Для пользователя (установка собранной версии)
1.  Склонируйте репозиторий и настройте `hosts.json` (см. [Конфигурация хостов](#-конфигурация-хостов)).
2.  Соберите проект: `node build.js` (собирает и `manifest.json`, и `dist/full/`).
3.  Откройте Chrome и перейдите на `chrome://extensions/`.
4.  Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
5.  Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку `dist/full/`.

### Для разработчика (сборка из исходников)
1.  Убедитесь, что установлен [Node.js](https://nodejs.org/).
2.  Настройте `hosts.json` и выполните `node gen-manifest.js`.
3.  Соберите проект: `node build.js` (esbuild-минификация, зависимости ставятся через `npx`).
4.  Для отладки без сборки можно загрузить корень проекта как распакованное расширение — но сначала выполните `node gen-manifest.js`, иначе `manifest.json` и `hosts.generated.js` не будут созданы.

## 🏗️ Структура проекта

```text
delProp/
├── manifest.template.json # Шаблон манифеста (MV3) с плейсхолдерами матчей
├── manifest.json          # Готовый манифест — генерируется, в .gitignore
├── hosts.example.json     # Заглушки хостов (в git)
├── hosts.json             # Реальные хосты — в .gitignore
├── gen-manifest.js        # Генератор manifest.json + hosts.generated.js
├── hosts.generated.js     # Runtime-конфиг (DELPROP_HOSTS) — генерируется, в .gitignore
├── background.js          # Фоновый сервис-воркер
├── build.js               # Скрипт сборки (gen + esbuild minification)
├── popup.*                # Интерфейс настроек и учёта отгулов
├── db/
│   └── db.json            # База новостей и данных расширения
├── home/                  # Модули для главного портала
│   ├── core.js            # Ядро: инициализация, хелперы, Mutation Observer
│   ├── header.js          # Плавающая шапка с прогрессом
│   ├── news.js            # Управление новостями
│   ├── misc.js            # Парсинг активности, переработки, модальные окна
│   ├── pivo.js            # Entry-point таймера
│   └── pivo/              # Подмодули таймера (разделены по ответственности)
│       ├── messages.js    # Тексты уведомлений для всех тем
│       ├── themes.js      # HTML-шаблоны 14 визуальных тем
│       ├── render.js      # Рендеринг прогресса по темам
│       └── core.js        # Логика таймера, перекуры, расчёт времени
├── archive/               # Модули для электронного архива
│   ├── filterHistory.js   # История поиска с привязкой к вкладкам
│   ├── filterAutocomplete.js # Автодополнение из дерева документов
│   ├── projectFilter.js   # Основной фильтр и «закрепы»
│   └── saveAddres.js      # Сохранение вкладок и синхронизация
├── patch/                 # Скрипты для инъекции в контекст страницы
└── utils/                 # Общие утилиты
    ├── time.js            # Расчёт рабочего времени, опозданий, форматирование
    └── settings.js        # Дефолтные настройки (single source of truth)
```
